# Provenance and Source Terms

Corn-DR combines transformed agricultural imagery and supplementary restoration
material originating from several public research datasets. Inclusion in this
release was confirmed by the dataset authors. This repository does not replace,
expand, or override the licenses and access conditions of those sources.

| Source | Role | Citation |
| --- | --- | --- |
| PlantVillage | maize disease semantics | <https://doi.org/10.3389/fpls.2016.01419> |
| PlantDoc | field-style plant disease semantics | <https://doi.org/10.1145/3371158.3371196> |
| IP102 | insect pest semantics | <https://doi.org/10.1109/CVPR.2019.00899> |
| GoPro | blur restoration material | <https://doi.org/10.1109/CVPR.2017.35> |
| Dense-Haze | dense-haze restoration material | <https://doi.org/10.1109/ICIP.2019.8803046> |
| NH-HAZE | non-homogeneous haze material | <https://doi.org/10.1109/CVPRW50498.2020.00230> |
| See-in-the-Dark | low-light restoration material | <https://doi.org/10.1109/CVPR.2018.00347> |
| SPA-Data | rain restoration material | <https://doi.org/10.1109/CVPR.2019.01255> |

Users are responsible for reviewing and complying with the original terms of
every applicable source, including attribution, research-only, and
non-commercial restrictions. In particular, a license attached to source code
must not automatically be treated as a license for dataset images.

Public sample metadata retains stable source identifiers, source dataset names,
original-image group identifiers, transformation status, degradation recipes,
and random seeds when available. Machine-specific absolute paths and private
environment details are removed.

If a source owner believes that material has been included incorrectly, please
contact the corresponding author of the associated manuscript and identify the
affected sample IDs.
