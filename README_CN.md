# Corn-DR 中文说明

Corn-DR 是一个面向玉米病虫害图像复合退化识别、图像复原和超分辨率研究的
数据集。它用于研究实际成像中可能同时出现的雨纹、雾霾类退化、模糊、低照度
和局部遮挡等问题。

> 发布状态：文档预览。数据压缩包与数据划分清单仍在整理，并正在逐项核查原始
> 来源及二次分发许可。本仓库目前尚未提供可下载的数据压缩包。

## 数据集范围

论文当前版本中的 Corn-DR 共包含 13,053 个样本：

| 数据划分 | 样本数 |
| --- | ---: |
| 训练集 | 12,083 |
| 验证集 | 570 |
| 测试集 | 400 |
| 总计 | 13,053 |

训练集包括 9,700 个具有玉米语义的基础退化样本、1,800 个困难退化扩展样本，
以及 583 个来自公开真实退化图像复原基准的补充样本。数据集先按照原始清晰
图像进行划分，再生成退化版本。因此，同一张原图及其全部衍生样本只会出现在
训练集、验证集或测试集中的一个子集内，以避免数据泄漏。

退化识别采用五个可同时出现的标签：

- `RAIN`：雨纹或类似雨纹的干扰
- `FOG`：雾或霾类大气退化
- `BLUR`：运动模糊、散焦模糊或相关模糊
- `LOW`：低照度
- `OCCL`：局部遮挡或异常，例如水滴、水渍、强反光覆盖或不规则遮挡物

## 必须说明的边界

Corn-DR 将玉米病虫害语义图像、受控生成的成对退化样本和公开图像复原基准中
的真实退化样本结合起来。这里的补充真实退化样本并不是新采集的玉米田间图像，
因此不能将其表述为新建的真实玉米田间数据集。

## 计划公开的内容

- 带稳定样本编号的训练、验证和测试划分清单
- 多标签退化标注以及来源和溯源字段
- 退化生成流程与复现实验所需的元数据
- 数据统计、完整性哈希值与核验说明
- 对于不能二次分发的源数据，提供其官方下载与重建说明

## 不公开的内容

- 已训练模型的权重和检查点
- 尚未公开的模型实现与系统集成代码
- 私有实验日志、账号密钥和机器相关文件
- 未确认二次分发许可的第三方原始图像

## 许可与第三方数据

本仓库现阶段不授予统一的数据许可。Corn-DR 包含或派生自多个公开科研数据集，
各来源的使用和二次分发条款并不完全相同，必须分别遵守。详细情况见
[数据来源与许可核查](docs/PROVENANCE_AND_LICENSES.md)。
