# Corn-DR v1.0.0

This is the first complete public release of Corn-DR.

It contains 13,053 aligned high-resolution targets, degraded 2x inputs, clean
low-resolution references, and per-sample JSON annotations, together with
12,470 local-occlusion masks, five split manifests, and dataset audit reports.

Large image directories are distributed as multipart tar archives. Download
all assets and follow the reconstruction commands in the repository README.
Verify every downloaded file against `SHA256SUMS.txt` before use.

Trained model weights, checkpoints, unreleased implementation code, and private
experiment logs are not included.
