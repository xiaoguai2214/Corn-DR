# Manifest Documentation

The verified release will provide one manifest per split. The exact columns will
be finalized after the experimental dataset and its original metadata are
recovered. At minimum, each record should contain:

| Field | Meaning |
| --- | --- |
| `sample_id` | Stable Corn-DR identifier |
| `split` | `train`, `val`, or `test` |
| `source_dataset` | Provenance source |
| `source_item_id` | Original source identifier or relative source path |
| `source_group_id` | Original clear-image group used to prevent split leakage |
| `content_domain` | Maize disease, maize pest, or supplementary restoration benchmark |
| `labels` | One or more of RAIN, FOG, BLUR, LOW, and OCCL |
| `is_synthetic` | Whether the degradation was generated by the Corn-DR pipeline |
| `degradation_recipe` | Versioned recipe identifier, when applicable |
| `random_seed` | Seed used to reproduce a generated sample, when applicable |
| `redistributable` | Result of the source-license audit |
| `sha256` | Integrity hash of a released file |

The CSV files are intentionally not included in this documentation preview.
Counts and schema must be checked against the exact dataset version used in the
reported experiments before publication.
